This section will list and introduce the blogs you have posted to [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj). Below are the three blogs we have published:

###  [Blog 1 - RIOT GAMES: PROCESSING 20 TB DAILY ANALYTICS DATA WITH AMAZON MSK ON AWS](3.1-Blog1/)
This blog introduces Riot Games' journey to process 20 TB of analytics data daily by replacing its legacy MapReduce batch pipeline with Amazon MSK (Managed Streaming for Apache Kafka). The new event-driven architecture powers near-real-time streaming analytics for League of Legends, VALORANT, and TFT, cutting query latency from 6 hours down to 5 minutes, enabling real-time anti-cheat detection, and saving $10 million in annual infrastructure costs.

###  [Blog 2 - FORMULA 1 (F1 INSIGHTS): REAL-TIME TELEMETRY PROCESSING & ML PREDICTIONS ON AWS](3.2-Blog2/)
This blog explores how Formula 1 delivers the F1 Insights real-time telemetry processing and ML prediction system on AWS. With over 300 IoT sensors per car generating 1.1 million data points per second, the architecture combines Amazon Kinesis Data Streams, AWS Lambda, Apache Flink, and Amazon SageMaker to power ultra-low-latency (under 200ms) broadcast graphics — including overtake probability, tire performance, and pit strategy predictions — for more than 1.5 billion TV viewers worldwide.

###  [Blog 3 - BLUESIGHT: MULTI-AGENT ORCHESTRATION ARCHITECTURE FOR GPO PROHIBITION COMPLIANCE ON AWS](3.3-Blog3/)
This blog introduces Bluesight's multi-agent orchestration architecture for GPO Prohibition compliance on AWS. Using Amazon Bedrock (Claude) as a GPO Orchestrator that delegates tasks to specialized worker agents (340BCheck, ShortageCheck, CostCheck) and a deterministic scoring pipeline running 13 signals, the solution achieves 100% deterministic accuracy while eliminating LLM hallucination risks in high-stakes 340B drug pricing compliance audits.
