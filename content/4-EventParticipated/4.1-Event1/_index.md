# Reflection Report: “GenAI-powered App-DB Modernization workshop”

### Event Objectives

- The final round of the Cloud Architect contest
- Introduction to AWS Security Agent
- Guidance and introduction to the AWS certification contest
- Sharing about DevOps and lessons learned from working as a DevOps engineer

### Facilitators

- AWS Team: Acted as host and MC for the contest. The AWS Team introduced the rules, coordinated each match, announced the scores, managed the use of special skills, and kept the pace for each round.

### Key Highlights

#### Reviewing AWS knowledge through a competitive format

The event made reviewing AWS knowledge more proactive than a typical lesson. Instead of just listening to explanations, participants had to follow each question, quickly recall related concepts, and compare potentially correct options.

The topic groups featured in the contest included:

- Compute services such as Amazon EC2, Auto Scaling, Elastic Load Balancing, and container services
- Storage services such as Amazon S3 and backup-related concepts
- Networking such as VPC, subnet design, routing, security groups, and high availability across multiple Availability Zones
- Identity and access such as IAM users, roles, policies, and least privilege
- Monitoring and cost such as Amazon CloudWatch and AWS Budgets
- Architecture design questions in the AWS Solution Architect style.

#### Introduction to AWS Security Agent

- Introduction to AWS Security Agent: an agent on AWS dedicated to security; it can review code to detect vulnerabilities and perform penetration testing.
- Discussed the current free tier
- Demo on a repository of a website hosted on AWS, demonstrating both capabilities: reviewing code on the repository and performing penetration testing on the website.

#### Sharing about DevOps and lessons learned from working

- Discussed the layers involved in operating a system and the scenarios when bugs or incidents occur.
- Shared a real-world industry perspective; the speaker currently works at Endava and shared the process when an error occurs in production, with the customer at the first layer (the speaker works at layer 1).
- Demoed how a system handles the situation when a component goes down on AWS.

#### Introduction to the AWS certification contest

- Introduction to the topics that may appear in the exam
- Guidance on how to take the exam
- Tips & Tricks
